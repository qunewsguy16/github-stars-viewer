# skills-manifest.txt
# Machine-readable manifest for "INSTALL NOW" items from DEPLOYMENT.md Part 4, section 1.
# Format (tab-separated): <method>\t<owner/repo>\t<target-or-note>
#
# Third field: for clone-skill it is "<target-dir> :: <optional human note>" (text
# before " :: " becomes ~/.claude/skills/<target-dir>); for pip/npm it is the command
# to run; for mcp/plugin/manual it is the instruction text.
#
# Methods:
#   clone-skill  git clone the repo shallow, copy the skill folder(s) (any dir containing
#                SKILL.md, else the whole repo) into ~/.claude/skills/<target>
#   pip          pip install command to run on the PC
#   npm          npm install command to run on the PC
#   mcp          claude mcp add command to register an MCP server
#   plugin       in-app "/plugin marketplace add owner/repo" or "/plugin install" step -
#                NOT scriptable from outside Claude Code, printed as an instruction
#   manual       anything else that needs a human decision/action
#
# Lines beginning with # are comments and are ignored by the install scripts.
